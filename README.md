## Installation

### Clone the Repository

```bash
git clone https://github.com/suhnshaine/IT0049-Final-Project.git
```

### Navigate to the Project Folder

```bash
cd IT0049-Final-Project
```

## Database Setup

1. Create a database named:

```text
final_pos_laravel
```

2. Import the database export file:

```text
database/final_pos_laravel.sql
```

3. Ensure Apache and MySQL are running in XAMPP.

## Running the Application

Start the development server:

```bash
php artisan serve
```

Open:

```text
http://127.0.0.1:8000/
```
